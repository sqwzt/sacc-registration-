# 🏆 SACC 科技创新大赛 · 报名网站

> **南京邮电大学 计算机学院科学技术协会（SACC）**  
> 2026 前端组 Summer of Code（SoC）· 完整实战项目


## 📌 项目简介

本项目是一个面向全校的**科技创新大赛报名网站**，参赛者可以在线查看比赛信息并填写报名表单。页面涵盖了比赛信息展示、完整的报名表单、实时表单验证以及提交反馈功能，并适配了电脑端与移动端。

这是我在 SACC Summer of Code 学习期间的**综合实战项目**，系统运用了 HTML、CSS、JavaScript 三件套，并遵循了模块化开发与版本控制规范。

> 🎯 **项目状态**：已完成必做功能及部分加分功能，代码已托管至 GitHub，具备完整的版本记录与项目文档。


## 🛠️ 技术栈

| 类别 | 技术 | 用途 |
|------|------|------|
| 结构 | HTML5 | 页面骨架与语义化标签 |
| 样式 | CSS3 | 布局美化、响应式设计、过渡动画 |
| 交互 | JavaScript (ES6) | 表单验证、DOM 操作、事件处理 |
| 版本控制 | Git & GitHub | 代码托管、版本管理与协作基础 |
| 辅助工具 | VS Code + Live Server | 本地开发与实时预览 |

> 📌 本项目为纯原生实现，未引入 Vue/React 等框架，符合 SoC 第二阶段学习目标。

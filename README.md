## 📌 项目简介

本项目是一个**科技创新大赛报名网站**，参赛者可以在线查看比赛信息并填写报名表单。页面包含比赛信息展示区、完整的报名表单、实时表单验证以及提交反馈功能，并适配电脑和手机端。

这是我在 SACC Summer of Code 学习期间的**完整实战项目**，综合运用了 HTML、CSS、JavaScript 三件套。

---

## 🛠️ 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 | 页面骨架与语义化标签 |
| CSS3 | 布局美化、响应式设计、过渡动画 |
| JavaScript (ES6) | 表单验证、交互逻辑、DOM 操作 |
| Git & GitHub | 版本控制与代码托管 |

> 本项目未使用 Vue/React 框架，纯原生三件套实现。
